Lab Session 1: Rust Basics & Control Flow

This directory contains the solutions for **Lab Session 1**, focusing on basic Rust syntax, variable mutability, primitive types, functions, and standard control flow.

Exercises & Implementation Details

* **Exercise A — Hello World & Variables:** 
  Demonstrates printing to stdout and understanding Rust's default immutability vs `mut`.
* **Exercise B — Functions & Control Flow:** 
  Implements custom functions returning values, using `if/else` expressions and loops (`loop`, `while`, `for`).
* **Exercise C — Temperature Converter:** 
  A practical exercise converting temperatures between Celsius and Fahrenheit using basic arithmetic and typed functions.
